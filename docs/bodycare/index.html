Q&A

よくある質問

予約はどうすればいいですか？

LINE からお願いします。空いている時間を見て、その場で予約できます。施術中は電話に出られないため、お電話でのご予約は承っておりません。

どんな服装で行けばいいですか？

動きやすい服装でお越しください。

健康保険は使えますか？

使えません。ケガ（骨折・脱臼・捻挫・打撲・挫傷）は、同じ建物の もみの木接骨院 で健康保険が使えます。

なぜ食事のことまで？

慢性の痛みや疲れには、毎日の食事や生活習慣も関わっています。体をつくるところから見直すと、変わりやすくなります。

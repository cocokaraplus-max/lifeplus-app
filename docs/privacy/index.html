プライバシーポリシー

合同会社LIFE PLUS（以下「当社」）は、このホームページ、LINEでのご予約、お問い合わせでお預かりする個人情報を、次のとおり大切に取り扱います。

1. お預かりする情報

  • LINEでのご予約：お名前・フリガナ・お電話番号、LINEの表示名とLINEのユーザーを見分ける番号、ご予約の内容（日時・メニュー・選んでいただいた症状）、ご来院の記録

  • 採用への応募：お名前・お電話番号・メールアドレス・応募の内容（ご経験・資格・ご希望など）
  • メール・お電話・FAX：お知らせいただいた内容

2. 使う目的

  • ご予約の受付・確認・変更のご連絡と、施術のため
  • お問い合わせへのお返事のため
  • 採用の選考と、応募された方へのご連絡のため
  • 予約の取り消しやご来院がなかったことの記録など、予約を正しく運営するため
  • サービスを良くするため（個人が分からない形にまとめて使います）

これらの目的のほかには使いません。営業や広告のメール・メッセージをお送りすることもありません。

3. ほかの会社へ渡すこと

法令にもとづく場合などを除いて、ご本人の同意なく、ほかの会社や人にお渡しすることはありません。

4. 外部のサービスの利用

  • LINE（LINEヤフー株式会社）：ご予約の受付とご連絡

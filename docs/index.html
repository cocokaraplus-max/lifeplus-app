豊田市丸山町

ひとつの建物に、3つの入口があります。

体を動かして暮らしを続けたい方のデイサービス、ケガや痛みをみる接骨院、慢性の痛みと向き合うボディケア。合同会社LIFE PLUSは、この3つを同じ場所で営んでいます。

入口の絵を押すと、それぞれのページが開きます。

3つの事業

ココカラプラス

機能訓練型デイサービス（地域密着型通所介護）

人の手による機能訓練を中心に、ご自宅でも続けやすい運動を一緒に取り組みます。3時間と7時間のご利用があります。

デイサービスのページ

もみの木接骨院

骨折・脱臼・捻挫・打撲・挫傷、交通事故のケガ

ケガの施術は健康保険が使えます。交通事故のケガは自賠責保険で施術を受けられます。予約制です。

接骨院のページ

HIROボディケアスタジオ

慢性の腰痛・肩こりなど（保険外）

トリガーポイントと筋膜へのアプローチで、くり返す痛みの原因を一緒に探します。予約制です。
